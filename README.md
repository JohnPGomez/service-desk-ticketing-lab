# ServiceDesk Pro — Professional ITSM Lab

A working browser-based Service Desk / ITSM portfolio project designed to demonstrate incident management, SLA awareness, ticket ownership, documentation, and support workflow concepts.

## Functional Features

- Professional dashboard with operational metrics
- Incident queue and live priority view
- Create new incidents
- Automatic priority calculation from Impact + Urgency
- Status workflow: Open / In Progress / Pending / Resolved
- Assignee management
- SLA due-time calculation by priority
- SLA-at-risk highlighting
- Search and filter by status/priority
- Ticket detail modal
- Work-note / troubleshooting timeline
- Demo incident loader
- JSON export
- Knowledge-base articles
- Analytics page with resolution rate and category distribution
- Browser persistence using localStorage
- Responsive desktop/mobile design

## Demo SLA Targets

- P1: 4 hours
- P2: 8 hours
- P3: 24 hours
- P4: 72 hours

These values are for demonstration only and do not represent a specific employer's production SLA.

## Run Locally

Open `index.html` in a modern browser.

## GitHub Pages

Upload these files to the repository root:

- `index.html`
- `styles.css`
- `app.js`
- `.nojekyll`
- `README.md`

Then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Portfolio Positioning

Use the wording:

**Personal ITSM / Service Desk Lab**

This project demonstrates service-desk workflow concepts in a custom browser application. It is not ServiceNow and should not be described as a production deployment.
